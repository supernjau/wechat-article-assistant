# 公众号文章助手

一款用于微信公众号官方编辑器的 Chrome 扩展，帮助公众号运营者更高效地完成文章排版。

它目前提供三项功能：

- **HTML 导入**：将排版好的 HTML 文件或 HTML 代码写入公众号正文。
- **全文关键词强调**：批量强调文章中的指定关键词，支持保存常用词库、只强调每个词第一次出现，并实时显示命中数。
- **往期推荐**：一键读取最近发表的文章（自动跳过图文），选择模板后插入“往期推荐”模块。

此外，插件改动正文前会自动备份，支持 **撤销与重做**。

文章正文、HTML 文件和插件设置只在本地浏览器中处理，不会上传到任何第三方服务器。

## 安装方法

本扩展暂未发布到 Chrome 应用商店，需要手动加载一次。以后正常使用时，无需重复安装。

### 第一步：下载插件

1. 打开本仓库页面。
2. 点击右上角绿色的 **Code** 按钮。
3. 点击 **Download ZIP**。
4. 下载完成后，解压 ZIP 文件。

也可以使用 Git 下载：

```bash
git clone https://github.com/supernjau/wechat-article-assistant.git
```

### 第二步：加载到 Chrome

1. 在 Chrome 地址栏输入 `chrome://extensions`，按回车。
2. 打开页面右上角的 **开发者模式**。
3. 点击左上角的 **加载已解压的扩展程序**。
4. 选择刚才解压得到的 `wechat-article-assistant` 文件夹。
5. 确认扩展列表中出现“公众号文章助手”。

### 第三步：在公众号后台启用

1. 登录[微信公众号平台](https://mp.weixin.qq.com/)。
2. 进入公众号文章编辑页面。
3. 刷新一次页面。
4. 页面右侧出现竖排的“文章助手”按钮，即表示加载成功。

点击 Chrome 工具栏中的扩展图标，再点击“打开文章助手”，也可以打开操作面板。

## 功能一：HTML 导入

适用于已经使用其他工具完成排版，希望将文章整体写入公众号正文的场景。

### 使用步骤

1. 打开公众号文章编辑页面。
2. 点击页面右侧的“文章助手”。
3. 选择 **HTML 导入**。
4. 点击 **选择 HTML 文件**，导入 `.html` 或 `.htm` 文件。也可以直接将 HTML 代码粘贴到输入框。
5. 在下方预览区检查正文效果。
6. 选择导入方式：
   - **覆盖正文**：清空当前正文，再写入导入内容。
   - **插入光标位置**：保留当前正文，并在光标所在位置插入内容。
7. 点击 **导入正文**。

### 注意事项

- 使用“覆盖正文”前，请确认当前编辑器中没有需要保留的内容。覆盖前会弹出确认；万一点错，也可以用面板顶部的“撤销”退回。
- 扩展会保留正文结构、常见内联样式和图片。
- 为了安全，扩展会移除脚本、外部样式表、事件属性和危险链接。
- 导入后仍建议在公众号编辑器中完整预览一次文章。

## 功能二：全文关键词强调

适用于英语教学、知识科普和职场写作等内容。输入关键词后，可以一次性强调全文中的相同词语。

### 使用步骤

1. 点击页面右侧的“文章助手”。
2. 选择 **关键词强调**。
3. 输入需要强调的关键词。每行输入一个，也可以用中文或英文逗号分隔。
4. 选择强调样式：
   - 黄色标记
   - 红色加粗
   - 蓝色下划线
5. 点击 **应用强调**。

### 词库、首次出现和命中数

- **词库**：把常用关键词存成有名字的词库（例如“外贸英语词汇”）。在“词库名称”里填名字，点 **保存当前为词库**；以后从下拉框选中它，关键词框就会换成这套词。名字相同会覆盖更新。选中词库后点 **删除词库** 可删除。词库只保存在本机浏览器里。
- **只强调每个词第一次出现**：勾选后，每个关键词只强调它在正文里最早出现的一处（不区分大小写）。不勾选则强调全文每一处。
- **正文命中**：输入关键词时，面板会实时显示每个词在正文里命中几处，以及应用后将强调几处，不会改动正文。命中 0 处的词会标成橙色，方便发现拼写错误。

如果需要撤销本插件添加的强调，点击 **移除本插件强调**。这个操作只会移除插件添加的样式，不会影响你手工完成的排版。

## 功能三：往期推荐

“往期推荐”可以读取公众号后台最近发表的文章标题和链接，自动生成一个适合放在正文结尾的推荐模块。

### 第一步：读取近期文章

1. 打开公众号文章编辑页面。
2. 点击页面右侧的“文章助手”，选择 **往期推荐**。
3. 点击 **读取最近文章**。
4. 插件会直接从公众号后台读取最近发表的文章，最多五篇，不需要先打开官方“超链接”窗口。

由原文整理再发的“图文”（图片消息）会被自动跳过，只推荐原文。插件会先取最近 10 条发表记录，去掉图文、已删除的文章和重复标题后，保留最新的 5 篇。

读取成功后，请检查每一篇文章的标题和链接。

如果后台接口暂时读取失败，插件会退回到读取已经打开的官方“超链接”窗口（在“链接内容”中选择“选择账号文章”并显示出文章列表），此时需要先手动打开该窗口。

### 第二步：检查文章链接

通过后台接口读取时，每篇文章都带有完整的链接，链接输入框会正常显示公众号文章地址。

只有在接口读取失败、退回到读取官方“超链接”窗口时，才可能出现只读到标题、没有链接的情况。此时链接输入框会显示为黄色，表示链接尚未补全。请手动粘贴对应的公众号文章链接，格式通常类似：

```text
https://mp.weixin.qq.com/s/...
```

为了避免生成无法点击的推荐项目，只要还有文章缺少有效链接，插件就不会执行插入操作。

### 第三步：调整推荐内容

读取完成后，可以继续调整：

- 修改文章标题。
- 修改或补充文章链接。
- 使用上移、下移按钮调整顺序。
- 删除不希望推荐的文章。
- 点击“添加文章”手动补充推荐内容。

模块最多保留五篇文章。

### 第四步：选择模板并插入

1. 从六种模板中选择一种：
   - 清爽列表
   - 数字目录
   - 编辑精选
   - 极简边框
   - 杂志索引
   - 工作室风格
2. 在“模板预览”中检查效果。
3. 选择插入位置：
   - **正文末尾**：适合常规的往期推荐。
   - **光标位置**：适合将模块插入指定段落之间。
4. 点击 **插入往期推荐**。
5. 回到公众号正文，确认推荐模块的位置和链接。

### 常见问题

#### 点击“读取最近文章”后没有读取到内容

请依次确认：

1. 是否已经刷新公众号文章编辑页面，使扩展加载最新版本。
2. 公众号是否有已发表的文章，并且页面仍处于登录状态。
3. 接口读取失败时，可打开官方“编辑超链接”窗口，选择“选择账号文章”并显示出文章列表后再点一次。

如果仍然无法读取，可以点击“添加文章”，手动输入标题和公众号文章链接。

#### 为什么链接输入框是黄色的？

这表示插件读取到了文章标题，但公众号后台没有向页面暴露对应链接。补充链接后，黄色提示会消失。

#### 为什么无法插入往期推荐？

请检查是否还有黄色链接输入框。每一篇推荐文章都必须填写有效的公众号文章链接。

#### 为什么读取到的文章少于五篇？

常见原因有两个：

- 最近的发表记录里有较多“图文”。插件只推荐原文，会跳过图文，而每次只取最近 10 条记录来筛选。
- 公众号发表过的文章本来就不多，或者其中有已删除的文章、标题重复的文章。

可以使用“添加文章”手动补充，或把推荐内容调整为少于五篇。如果是接口读取失败、退回到官方窗口读取，则可能因为官方窗口当前可见的文章不足五篇，可向下滚动官方窗口后再读取一次。

## 撤销与重做

面板顶部（标签页下方）有一条撤销栏，显示上一步操作，例如“上一步：应用强调（10:32）”，旁边是 **撤销** 和 **重做** 按钮。

- 插件每次改动正文之前，都会先备份当前正文。覆盖正文、插入 HTML、插入往期推荐、应用强调、移除强调，这五种操作都可以撤销，最多保留最近 10 步。
- 点 **撤销**，正文恢复到那次操作之前。撤销之后可以点 **重做** 找回；做了新的插件操作后，重做记录会清空。
- 没有实际改动的操作（例如应用强调却没有命中任何关键词）不占一步。
- 如果取不到当前正文，无法备份，这次操作会被取消并给出提示，不会在没有退路的情况下改写正文。

注意：

- 只记录插件自己的操作。你在编辑器里手动输入、删除的内容不会被记录，撤销会把正文整体退回到插件操作之前的样子，其间手动修改的内容也会一起退掉；需要时可以用 **重做** 找回。
- 备份只保存在当前页面的内存里，刷新页面或关闭标签页后会清空。公众号文章本身由公众号后台保存，不受影响。
- “应用强调”“移除强调”会把正文整体重新写入编辑器，写入后光标位置会被重置。不满意时可以直接撤销。

## 更新插件

如果通过 ZIP 文件安装：

1. 重新下载并解压最新版本。
2. 打开 `chrome://extensions`。
3. 找到“公众号文章助手”。
4. 点击刷新图标。
5. 回到公众号文章编辑页面，再刷新一次页面。

如果通过 Git 下载：

```bash
git pull
```

然后在 `chrome://extensions` 中刷新扩展，并刷新公众号文章编辑页。

直接用浏览器打开 `preview.html`，可以在模拟编辑器中体验三个功能。模拟页面右侧包含五条公众号文章链接，用于测试“往期推荐”读取（本地预览没有公众号后台，读取会走备用的页面读取方式）。

## 隐私与安全

- 插件不连接任何第三方服务器。
- “读取最近文章”会向公众号后台（`mp.weixin.qq.com`）自己的接口发起一次只读请求，使用你当前已登录的身份，读取你自己公众号最近发表的文章列表。请求不会发往其他域名，插件也不会修改或发布任何文章。
- 文章正文和 HTML 文件只在浏览器本地处理。
- 本地设置（关键词、词库、推荐文章等）保存在 Chrome 扩展存储中。撤销用的正文备份只保存在页面内存里，刷新后清空。
- HTML 导入会过滤脚本、事件属性和危险链接。
- 往期推荐只接受 `https://mp.weixin.qq.com/s/...` 格式的公众号文章链接。

## 开发与验证

安装依赖不是必需的。如果需要运行自动化检查，请确保电脑已安装 Node.js，然后执行：

```bash
npm test
npm run check
```

公众号后台改版后，优先检查：

- `src/editor-adapter.js`：正文定位、覆盖和光标插入，以及通过官方编辑器接口读写正文。
- `src/content.js` 中的 `fetchRecentArticles()`（`/cgi-bin/appmsgpublish` 接口）和 `scrapeRecentArticles()`（官方超链接窗口读取，作为备用）。

开发时请注意：

- 官方编辑器不认直接修改页面元素。任何改动正文的功能都应通过 `EditorAdapter`（官方编辑器接口）读写正文，并通过 `recordedWrite` 或 `transformBody` 记入撤销历史。
- 官方编辑器写回正文时会去掉自定义属性并改写样式，所以“关键词强调”按样式识别自己加的标记（见 `content.js` 中的 `HIGHLIGHT_KEY_STYLES`）。修改强调颜色时需要同步修改。
